棋盤格代表超出 sRGB 色域：不裁切通道、不顯示替代色，也不計分。等分圓延伸至棋盤格的部分只有理論位置。

Oklab 是三維空間，每張圖只呈現通過目標的一個二維剖面。預設固定 L，無法呈現明暗差；可切換 a / L 或 b / L 檢查明暗。

滑過預覽，按一下固定。聚焦圖面後可用方向鍵移動，Shift 加大步幅；Enter 固定，Esc 回到目標。等分標籤可點選強調。

同一組答案的分差與傷害

各曲線使用完全相同的實際 RGB 答案。空白時自動選取 V4 的 90／70／30 分色票；此為合成範例，不能代表真人分布。

代表性 Oklab 色差

理論距離使用同一個正式評分函式；實際色票分數另以 RGB8 重算。

等分線以遊戲的未取整評分函式反求半徑，不使用任意間距。畫面以有限網格與 8 位元 RGB 取樣，所以實際顯示色彩可能略偏離理想剖面／等分線；檢視分數會以顯示的 RGB，重新呼叫遊戲的 grade 函式（0.001 分精度）。

此工具只處理 sRGB；顯示器、亮度與周遭環境會影響主觀感受。沒有載入 Firebase，也不會儲存參數。
